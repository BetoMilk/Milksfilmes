STREAMBOX - PROTOTIPO

Como usar:
1. Abra index.html no navegador (Chrome, Edge, Firefox ou Safari).
2. Clique em "Adicionar" para cadastrar um vídeo.
3. Informe título, categoria e URL do player/vídeo. Capa e descrição são opcionais.
4. Os cadastros e favoritos ficam salvos no armazenamento local do navegador (localStorage).

Notas:
- Links do YouTube e Vimeo são convertidos para URLs de embed automaticamente.
- Links diretos .mp4, .webm e .ogg são exibidos em player de vídeo.
- Outros links são tratados como player incorporável. Se o site bloquear iframe, use "Abrir no site original".
- Este protótipo não possui login, sincronização entre dispositivos nem backend.
- Use links de vídeos que você tenha autorização para acessar e incorporar.
